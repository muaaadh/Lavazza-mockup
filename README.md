# Lavazza Maldives, demo shop

Static demo of an online shop for Lavazza in the Maldives. No build step and no server: open `index.html`
through any static web server.

    npx serve .        # or any static server, then open the printed address

Pages: `index.html` (home), `shop.html`, `product.html`, `checkout.html` (with a payment gateway demo),
`track.html` (order tracking) and `admin/` (back end demo).

Everything a visitor or the admin does is saved in that browser's localStorage. Nothing is sent anywhere and
no payment is taken. Prices, stock and orders are sample values.

The catalogue in `assets/js/data.js` is generated by `tools/build_data.py`. Do not edit it by hand.
